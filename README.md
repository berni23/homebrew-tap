# berni23/homebrew-tap

Homebrew tap for [laight](https://github.com/berni23/laight): run teams of coding agents in tmux
from YAML workflows, with one queue for every human decision.

```bash
brew install berni23/tap/laight
```

The casks here are generated by GoReleaser on each laight release; don't edit them by hand.
Issues and contributions go to the [laight repository](https://github.com/berni23/laight).
